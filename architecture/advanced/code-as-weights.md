# Code-as-Weights & Symbolic Paths

## Concept
Instead of relying solely on dense tensor weights, represent knowledge and skills as:
- Deterministic code paths and algorithms
- Structured decision graphs
- Prompt templates and tool definitions
- Symbolic / logical reductions where applicable

## Benefits
- Extremely low compute for well-defined operations (e.g. sorting, parsing, verified math steps)
- Composable and versionable via Git
- Can be mixed with sparse neural components

## Limits
- Does not replace learned representations for open-ended reasoning, language, or novel problem solving
- Best used as a hybrid: neural routing + code execution for verifiable sub-tasks

## Integration
The digital datacenter can route certain tokens or sub-tasks to code executors instead of neural experts.
