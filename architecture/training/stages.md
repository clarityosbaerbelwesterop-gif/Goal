# Training Stages (Detailed)

## Stage 1: Base MoE Pre-training
- Premium data + Tempo Training + AES
- Focus: language, basic reasoning, code, math foundations

## Stage 2: Verifiable Reasoning Distillation (VRD)
- Distill only traces that pass verification (proofs, tests, formal checks)

## Stage 3: Constitutional + RLAIF Alignment
- Principle-based critique and preference optimization

## Stage 4: Long-Horizon Agentic Fine-tuning (LHAC)
- Multi-step trajectories, computer use, sub-agent coordination

## Stage 5: Meta-Adaptive Learning (MALL)
- In-context adaptation and continual learning episodes

## Stage 6: Final Hardening
- Preference optimization, safety, benchmark-oriented refinement

Each stage uses the tiered storage and virtual mesh for scale.
