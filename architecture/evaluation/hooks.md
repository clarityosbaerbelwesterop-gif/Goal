# Evaluation Hooks

## Built-in Signals
- Tempo efficiency (depth used vs. correctness proxy)
- Expert specialization purity (AES)
- Verifiable trace pass rate
- Long-horizon completion rate
- Domain balance over rolling window

## Checkpoint Metadata
Every rolling checkpoint records:
- Streamed volume
- Effective parameter representation
- Current tempo and thermal load
- Domain statistics
- Last evaluation proxies

These hooks allow continuous monitoring without full model extraction.
